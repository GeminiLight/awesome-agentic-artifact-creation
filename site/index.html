Interactive framework

A live construction loop.

Follow actions, observations, verification, and feedback as an artifact takes shape.

An interactive three-dimensional construction loop. A task specification enters the construction policy, which acts on an operational representation. Runtime verification observes the result and either accepts a delivered artifact or returns feedback to the policy.
