Artifact becomes the next task

An interactive three-dimensional construction process. A task specification enters the construction policy, which acts on an operational representation. Runtime verification observes the result, accepts a delivered artifact, and the artifact can begin the next task cycle.

Reading guide

Understand the field.

What is agentic artifact creation?

Agentic artifact creation uses AI systems to construct an artifact, inspect intermediate results, and revise their decisions using feedback. The survey examines construction policy, operational representation, and runtime verification across different output media.

Which artifacts does the catalog cover?

The catalog organizes outputs into six families: textual, visual, audio, video, spatial, and behavioral artifacts. Examples include documents, images, music, videos, 3D scenes, and executable software. A second axis describes the application context.

How are systems and benchmarks selected?

Entries are maintained in an open, audited dataset. Systems construct artifacts; benchmarks evaluate relevant capabilities. Publication status and taxonomy labels remain visible for each record. See the audit protocol for inclusion rules and evidence.

How can I use or cite this resource?

Start with the survey for the framework, explore the interactive catalog for specific papers, or download the catalog JSON. The BibTeX citation identifies the survey; individual paper links lead to their original sources.
